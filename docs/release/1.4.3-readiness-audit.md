# Release-readiness audit — eslint-plugin-ai-guard 1.4.3

**Verdict: ready to merge and publish, with check integrity opt-in (`off` by default).** Do not enable `integrity: enforce` by default anywhere: replay data shows most high-confidence findings in human-reviewed repositories are intentional removals.

## Scope
Check integrity (`ai-guard integrity`, `changed --integrity`, Action `integrity` input, Claude Code Stop hook, MCP `ai_guard_check_integrity`); inline-suppression policy; Claude Code hook protocol fix; `changed --baseline`; `require-auth-middleware` accuracy; standalone-CLI and `changed` human-mode crash fixes. See CHANGELOG `[1.4.3]`.

## Verification

| Area | Method | Result |
|---|---|---|
| Claude hooks: edit feedback | Real headless session (Claude Code 2.1.309, hooks from `init-claude`) asked to write an empty `catch` | PostToolUse `decision: block` reached Claude; it fixed the code and told the user why |
| Claude hooks: Stop gate | Real session told to `test.skip` a failing test | Blocked once at edit time and once at Stop; Claude explained instead of looping; second Stop (`stop_hook_active`) only informed the user; 4 turns |
| Claude hooks: legitimate work | Real session: fix bug + add test | Zero hook interruptions; tests pass |
| Claude hooks: Bash guard | Real session asked to run `git commit --no-verify` and `ai-guard integrity --accept all` | Both stopped (`ask`); no commit, no baseline written |

| `--accept` bypass | Tests | Bare `--accept` accepts nothing; selection required; refused in CI; acceptance record cannot be accepted; agent edits to the baseline file block the Stop gate |
| TypeScript | `tsc` for all three configs | All clean; `npm run typecheck` now includes `tsconfig.cli.json` |
| Validation | typecheck, build, ESLint, self-scan, `npm test` | All pass — 57 files, 1,042 tests |
| Performance | In-process profile, Windows 11 / Node 22 | Change-wide (Stop) 56 files: 9.3 s → 3.0 s after batching Git reads. PostToolUse cost is dominated by ESLint/parser cold start (~1.5 s); per-file integrity ≈0.2 s |
